## Deskripsi
Program untuk menganalisis nilai siswa, menghitung rata-rata,
menentukan nilai minimum dan maksimum, serta menghitung
jumlah siswa yang lulus dan tidak lulus.

## Fitur
- Input dan validasi nilai siswa.
- Menghitung rata-rata nilai.
- Menampilkan nilai minimum dan maksimum.
- Menentukan status kelulusan dengan batas 60.
- Menyimpan hasil analisis ke file.

## Persyaratan
Python 3.x

## Cara Menjalankan
python main.py

## Pengujian
Jalankan pengujian sesuai test case pada folder tests.
